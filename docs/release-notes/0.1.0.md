First release of Crosswinds for the Xteink X4: CrossPoint Reader 1.6.5 plus a
maritime trading game on the Home screen.

**Install:** flash `crosswinds-0.1.0-x3-x4.bin`. The README covers backing up the
device first and going back to CrossPoint.

**Tested:** one X4, flashed over USB. Opening the game, playing, quitting with
hold-BACK and from the Company Menu, and resuming all worked. A company saved by the
standalone firmware opened intact (it is copied to the SD card on first start). Free
heap with the game open was about 99 to 101 KB, against 129 KB on the Home screen.

**Not tested:**
- X3, X4 Pro and the other CrossPoint boards. This image is the X3/X4 one; the game is hidden on an X3.
- The update check against a published release. This is the first one.
- Flashing the `.bin` alone at `0x10000` (see the README).

**Limits:** buttons only, English only, no sound. Ships move only while the game is open.

**Changes from CrossPoint 1.6.5:** the Home entry, version number, HTTP User-Agent,
and update source. See `docs/CROSSWINDS.md`.

**Credits:** the code and in-game text were written with Claude Code and Codex; the artwork was
generated with OpenAI's image tool. `NOTICE` lists the rest. If your X4 was USB-locked
when you bought it, read the warning in the README before flashing anything.
